# Deploy

- [`observability/`](observability): configuration for the OpenTelemetry Collector, Prometheus, Loki, Tempo and Grafana that `compose.yaml` mounts ([ADR 5](../docs/adr/0005-opentelemetry-agent-and-one-collector.md)). The Grafana dashboard is generated by [`scripts/build_dashboard.py`](../scripts/build_dashboard.py); regenerate it with `make dashboard`.
- [`webhook-mock/`](webhook-mock): a stand-in for a Slack incoming webhook. The policy service posts escalations to it, and it shows them at http://127.0.0.1:8091 on a page that escapes every message and runs no scripts. `make test-webhook-mock` tests it.
- [`flags/`](flags): Mercadillo's feature flags, one `<service>.latest_release` per service, which `toggle_flag` switches. `make test-flags` tests it.
- [`policy/`](policy): the facts file the policy engine reads.
- Helm charts and a kind cluster may come in the last phase, if time allows ([ADR 3](../docs/adr/0003-docker-and-make-are-the-only-prerequisites.md)). They do not exist.
