# Tool servers

MCP servers in TypeScript, on the official MCP SDK: `mcp-metrics`, `mcp-logs`, `mcp-traces`, `mcp-changes` and `mcp-runbooks`, which are read-only and serve either the live stack or recorded snapshots, and `mcp-actions`, whose only tool creates a proposal and executes nothing ([ADR 2](../docs/adr/0002-the-model-proposes-the-code-decides.md)).

**Status:** not started. Built in Phase 3, except `mcp-actions`, which arrives with the policy engine.
